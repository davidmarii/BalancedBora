# BalancedBora AI

AI-powered livestock feed formulation for affordable, climate-smart dairy farming in Africa.

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Lucide React Icons
- GitHub Pages (deployment)

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run deploy
```
